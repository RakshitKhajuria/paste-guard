Changelog

What changed in each version of the extension. Project notes come first, then each version.

Closed source

25 April 2026 The project's code is now closed source. The extension's behaviour and privacy promises are unchanged.

Version 1.2.0

  • Restore mode (on by default): the AI sees placeholders like [EMAIL_1]; in its replies, your browser shows the original values again. This happens only on your device. The values are kept in memory only, per site, for up to 4 hours, and are forgotten when the browser closes or when you press Forget stored values in the popup.
  • With Restore on, a value keeps the same placeholder across pastes in a session. The message box always keeps showing placeholders.
  • A small pill on the page shows how many values were restored. Press Alt+R, or the pill button, to switch between original values and placeholders.
  • Mask this: select words in the message box and press Alt+Shift+M (or the Mask this chip). They are replaced by a placeholder and added to a personal dictionary of up to 10 words, which is stored on your device and masked in every future paste.
  • The website has a new interactive page, Try Restore and Mask this, that simulates the whole flow in your browser with nothing uploaded.
  • Because of Restore, the extension now reads page text on the supported sites to find placeholders in replies. It still sends nothing anywhere.

Version 1.1.0

  • Numbered placeholders: [EMAIL_1], [EMAIL_2], [API_KEY_1]. The same value gets the same number within a paste.
  • Ignore button on every dialog row. Only a salted one-way hash is stored, and the list can be cleared from the popup.
  • Five more AI chat sites: Perplexity, Copilot, Grok, DeepSeek and Mistral.
  • Regional detectors: UPI IDs, IFSC, GSTIN, labelled bank account numbers, IBAN and UK National Insurance numbers.
  • Many more API key and token formats, connection strings with passwords, authorization headers and private key blocks.
  • A welcome page on first install with a practice box that uses the real detectors.
  • Redesigned popup and paste dialog with light and dark themes and reduced-motion support.
  • Safer failure handling: an internal error can no longer lose or block a paste. This is covered by automated tests.
  • Custom rules (Pro, locked in this version) are validated and time-limited so a bad pattern cannot slow a paste.

Version 1.0.0

  • First version: scans pastes on ChatGPT, Claude and Gemini for emails, phone numbers, cards, Aadhaar, PAN, US SSNs and common API keys, and offers to paste a masked version.
  • Fully local: no network requests, no analytics, one permission (storage).
