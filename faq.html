Paste Guard FAQ

Short, direct answers about what Paste Guard does, what it does not do and how to check it yourself.

What does it detect?

Emails, phone numbers, card numbers (with a checksum), Aadhaar, PAN, US Social Security numbers, UPI IDs, IFSC codes, GSTIN numbers, labelled bank account numbers, IBANs, UK National Insurance numbers, API keys and tokens from many providers, private key blocks, JWTs and connection strings that contain passwords. The What it detects page is generated from the code, so it always matches the version you install.

Does it send my data anywhere?

No. Detection runs on your device inside the browser. The extension makes no network requests, loads no remote code, has no analytics and needs no account. The only data it stores, on your device, is your settings, a counter of protected pastes, and, if you use Ignore, one-way hashes of values you chose to ignore. It never stores pasted text.

How can I check that?

  • Open chrome://extensions, then Details for Paste Guard, to see its permissions: storage, plus the AI sites listed below.
  • With Developer mode on, inspect the service worker and the popup and watch the Network tab while you use it. It stays empty.
  • Paste a made-up key on a supported site with the Network tab open and see that the paste itself makes no request.
  • Look at the installed files: the extension's JavaScript is delivered to your browser, so you can browse it in DevTools (Sources tab) from chrome://extensions.

The steps are on the home page. You can also try the same detectors on the scanner page with the Network tab open.

Which sites does it work on?

ChatGPT, Claude, Gemini, Perplexity, Copilot, Grok, DeepSeek and Mistral (their chat sites). It does nothing on any other website.

What happens when it finds something?

A dialog lists what was found, with numbered tags and a short preview. You choose Paste masked (each value is replaced with a tag such as [EMAIL_1]), Paste anyway, or Cancel. Auto-mask mode skips the dialog and pastes the masked version. Ignore on a row means that exact value is not flagged again.

What can it not do?

  • It matches patterns, so unusual formats can be missed and look-alikes can be flagged.
  • It does not understand names, addresses or free-text confidential content.
  • It reads text only, not images. It watches pastes, not typing or file uploads, and with Restore on it reads page text on the supported sites to find placeholders in replies.
  • It does not take back anything already sent.

It is a safety net, not a guarantee, and not legal or compliance advice.

How do I report a missed format?

Email rkhajuira12345@gmail.com with the name of the provider or document and the shape of the value. Please use made-up samples only and never send a real secret, key or ID. Describe the shape (length, prefix, character set) rather than a real example if you can.

What is Restore?

The AI only ever receives placeholders such as [EMAIL_1]. When its reply uses a placeholder, Paste Guard shows your original value in that reply on your screen, so the answer reads naturally. It is on by default and can be turned off in the popup. The values are kept in memory only, per site, for up to 4 hours, and are forgotten when you close the browser or press "Forget stored values now". Your message box always keeps the placeholders, so an original value is not sent by accident. Alt+R (Option+R on a Mac) switches between originals and placeholders.

Can the website see my restored values?

Restored values are ordinary text on the page, so the site's own scripts could in principle read them, as they can read anything else shown on the page. Paste Guard never sends them anywhere. If that matters for what you are working on, turn Restore off in the popup: it then stores and restores nothing.

What is the personal dictionary?

Select words in the message box (a client or project name, say) and press Alt+Shift+M (Option+Shift+M on a Mac) or the "Mask this" button. They are replaced by a placeholder and added to a list of up to 10 words kept on your device, so they are masked in every later paste. Matching is whole-word and ignores case. You can remove words in the popup.

Is it free?

Yes. The extension is free, with no account and no tracking.

What will Pro be?

A Pro option with custom rules (your own words and patterns) is planned. It is locked in the current version and nothing in the extension takes payments. No price has been set.

Who is behind it, and how do I contact them?

Questions, bug reports and missed formats can go to rkhajuira12345@gmail.com. Please use made-up samples only.

Can I try it without installing?

Yes. The scanner page runs the same detectors in your browser on a made-up example. It is read only: you cannot type or paste your own text there. Nothing is uploaded.
