Paste Guard Privacy Policy

Last updated: October 26, 2026 (version 1.2.0)

Paste Guard is a browser extension that checks text you paste into AI chat websites and offers to mask sensitive data first.

What we collect

Nothing. Paste Guard does not collect, record, or receive any personal data, pasted text, browsing history or usage statistics. There is no account, no server and no analytics.

What we send

Nothing. Paste Guard makes no network requests. Pasted text is checked on your device, in memory, and is never written to disk, logged or transmitted.

What is stored on your device

Only the following, in your browser's local extension storage:

  • Your settings: on or off, mode, and which detectors are enabled.
  • A number counting how many pastes were protected.
  • If you press "Ignore" on a detected item: a salted one-way hash (SHA-256) of that value, so it is not flagged again. The value itself is never stored and cannot be read back from the hash. You can clear this list at any time from the extension's popup.
  • Your personal dictionary: if you use "Mask this" to add words, those words are stored as plain text, because they are what the extension has to look for in later pastes. They are stored only on your device, up to 10 words, and you can remove any of them or clear them all in the popup.

You can remove all of this at any time from the popup or by uninstalling the extension.

Restore (temporary, memory only)

When "Restore original values in replies" is on (it is on by default), the extension keeps a temporary list that pairs each placeholder it used (for example [EMAIL_1]) with the original value, so it can show your original value again in the AI's reply. This list:

  • lives only in the browser's memory-only extension storage (chrome.storage.session), per website;
  • is never written to disk and is cleared when you close the browser;
  • expires after 4 hours, holds at most 500 entries per site, and can be cleared at any time with "Forget stored values now" in the popup;
  • is never sent anywhere.

To find placeholders in replies, the extension reads the text of the page on the supported websites listed below. It only changes text that is not in a message box, and it never puts an original value into the message box, so the AI only receives placeholders. Because restored values are shown as ordinary text on the page, the website's own scripts could in principle read them, just as they can read anything else shown on the page. If you do not want that, turn off "Restore original values in replies" in the popup; the extension then stores and restores nothing.

Where it runs

Paste Guard only runs on these websites and does nothing on any other site:

  • chatgpt.com
  • claude.ai
  • gemini.google.com
  • perplexity.ai and www.perplexity.ai
  • copilot.microsoft.com
  • grok.com
  • chat.deepseek.com
  • chat.mistral.ai

Welcome page

When you first install Paste Guard it opens a welcome page that is part of the extension. It uses made-up example data and makes no network requests.

Permissions

  • storage: to save the settings, counter and ignore list described above.
  • Access to the websites listed above: to see paste events on those pages and show the warning, to read the page text to find placeholders in replies (Restore), and to show the optional "Mask this" button next to text you select in the message box.

Changes

If this policy changes, for example if optional paid features are added later, this page will be updated and the change described before the feature ships.
