Try Restore and Mask this

See the whole 1.2.0 flow in your browser: paste something sensitive, mask it, let a pretend AI reply, and watch your original values come back on your screen only.

This page is a local simulation. Nothing is uploaded or stored. It runs the same detectors and the same placeholder list code as the extension, in this page's memory. Reload and it is all gone.

  1. 1
    Mask

    Paste text. Paste Guard swaps each sensitive value for a placeholder.

  2. 2
    Send

    The AI receives only the placeholders. That is all it ever sees.

  3. 3
    Restore

    When the reply uses a placeholder, your screen shows your value again.

      The chat

      Messages appear here. Paste the example, choose Paste masked, press Send, then ask the fake AI to reply.

      Values remembered in memory: 0

      In your own message, the value shows again once it is in the chat, because it is ordinary text on the page. The AI still received only the placeholder. In the real extension the message box always keeps the placeholders. Restored values are underlined here so you can see them; the extension does not underline them.

      Where your data lives

      Restore and the dictionary add a little stored data. Here is all of it.

      WhatWhereHow longSent anywhere?
      Placeholder and original value list (Restore)Browser memory only (extension session storage), per siteUp to 4 hours, 500 entries, cleared when the browser closes or you press ForgetNo
      Personal dictionary wordsYour device, extension local storage, plain textUntil you remove themNo
      Ignored valuesYour device, as salted one-way hashesUntil you clear themNo
      Settings and the protected-paste countYour deviceUntil you uninstallNo
      Original sensitive values anywhere elseNever written to disk, page attributes, URLs or the consolen/aNo
